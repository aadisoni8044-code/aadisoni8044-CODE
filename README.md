## Active Projects & Architecture

### 💿 [Speedy OS](https://github.com/YOUR_USERNAME/SpeedyOS)
A custom, hobby Monolithic Operating System written from scratch using **NASM Assembly** and **C/C++**.
* **Boot Sequence:** Implements a custom bootloader for direct hardware control, bypassing standard OS layers.
* **Kernel Operations:** Handles low-level memory management, direct register manipulation, and executes in ring-0 for maximum performance.
* **Execution:** Interlines directly with x86 architecture constraints to handle system interrupts and bare-metal execution.

### ⚙️ [Open MS (Open Machine System)](https://github.com/YOUR_USERNAME/OpenMS)
A high-performance system programming language engineered from scratch in C++.
* **Compiler/Interpreter Pipeline:** Features a custom Lexer for tokenization, a strict Parser, and abstract syntax tree (AST) generation.
* **System Integration:** Built to serve as the native, compiled scripting and automation subsystem directly inside Speedy OS.
